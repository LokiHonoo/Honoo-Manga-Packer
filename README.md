## INTRODUCTION

漫画和图包的打包辅助工具。支持 ZIP/RAR/7Z/PDF 解压缩或重新打包到无压缩 ZIP 文件。

支持尝试使用密码解包加密的文件。此功能由 [SharpCompress](https://github.com/adamhathcock/sharpcompress) 实现，RAR5 解压不完全可用。

移除广告页功能暂时不可用。
