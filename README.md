## INTRODUCTION

漫画和图包的打包辅助工具。支持 ZIP/RAR/7Z/PDF 解压缩或重新打包到无压缩 ZIP 文件。

支持尝试使用密码解包加密的文件。此功能部分可用。

支持移除广告页。需要广告页采集软件生成的广告列表文件。
